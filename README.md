# Marsupio — version web

Le stock dans la poche. Par un tech, pour les techs.

Version web (iPhone, ordinateur) de l'appli Marsupio. Ce dépôt ne contient que le code de l'appli :
les données (stock, catalogue, agence) sont dans Firebase, protégées par la connexion et les règles d'accès.
Ne pas modifier à la main : ce dossier est généré depuis le dépôt privé de l'appli.
